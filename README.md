# Vault Viewer

GitHub 프라이빗 저장소에 올린 Obsidian 볼트를 폰에서 읽기 위한 뷰어. 문서를 열 때마다 GitHub API로 받아 오고 기기에 저장하지 않는다.

- 처음 열면 저장소(`owner/repo`)와 fine-grained 토큰(해당 저장소만, Contents: Read-only)을 입력한다. 토큰은 브라우저 localStorage에만 저장된다.
- 목록은 탭 세 개: 최근 읽음(이 기기에서 연 노트, 최대 30개), 최근 변경(최근 커밋 30개에서 바뀐 노트), 전체(폴더 트리, 이름순·최근순 전환. 최근순은 노트별 마지막 커밋 시각을 GraphQL로 받아 온다).
- 지원: 파일명 검색, `[[링크]]`·`[[링크|별칭]]`·`[[링크#제목]]`·`![[이미지]]`, 상대 경로 링크·이미지, 콜아웃, 프론트매터 숨김, 다크 모드.
- mermaid 다이어그램은 해당 노트를 열 때만 라이브러리를 받아 그린다.
- 미지원: dataview 코드블록(코드로 표시), 본문 전문 검색, 편집. 목록에는 md만 나오므로 노트가 임베드하지 않은 이미지는 열 수 없다.
